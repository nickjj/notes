# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a
Changelog](https://keepachangelog.com/en/1.0.0/).

## [Unreleased]

- Nothing yet!

## [0.3.1] - 2026-03-28

### Added

- `-v|--version|version` to get the current version

## [0.3.0] - 2021-12-04

### Changed

- Switch from `bash` to `sh` to be POSIX compliant (functionality wise it works the same)

## [0.2.0] - 2020-02-09

### Added

- Offer to create the notes directory if it doesn't exist

### Changed

- Scope files to `YYYY-MM` instead of `YYYY-MM-DD`
- Default notes directory to `$HOME/notes`

## [0.1.0] - 2019-12-25

### Added

- Everything!
